# OSS Helper

For open source maintenance work, use the matching skill below. Resolve these links from the installed extension directory containing this BOB.md, never from the current working directory. Read the selected SKILL.md and follow its initialization and guideline instructions.

| Task | Skill |
|---|---|
| Fix, analyze, create or triage issues | [oss-issues](plugin/skills/oss-issues/SKILL.md) |
| Review, merge or backport pull requests | [oss-review](plugin/skills/oss-review/SKILL.md) |
| Fix CI failures and quality findings | [oss-ci](plugin/skills/oss-ci/SKILL.md) |
| Triage vulnerabilities and manage advisories | [oss-security](plugin/skills/oss-security/SKILL.md) |
| Configure projects, rules and workspaces | [oss-project](plugin/skills/oss-project/SKILL.md) |
| Plan and execute quality checks | [oss-qe](plugin/skills/oss-qe/SKILL.md) |
