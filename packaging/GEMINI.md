# OSS Helper

For open source maintenance work, use the matching skill below. Resolve these links from the installed extension directory containing this GEMINI.md, never from the current working directory. Read the selected SKILL.md and follow its initialization and guideline instructions.

| Task | Skill |
|---|---|
| Fix, analyze, create or triage issues | [oss-issues](@SKILLS_PATH@/oss-issues/SKILL.md) |
| Review, merge or backport pull requests | [oss-review](@SKILLS_PATH@/oss-review/SKILL.md) |
| Fix CI failures and quality findings | [oss-ci](@SKILLS_PATH@/oss-ci/SKILL.md) |
| Triage vulnerabilities and manage advisories | [oss-security](@SKILLS_PATH@/oss-security/SKILL.md) |
| Configure projects, rules and workspaces | [oss-project](@SKILLS_PATH@/oss-project/SKILL.md) |
| Plan and execute quality checks | [oss-qe](@SKILLS_PATH@/oss-qe/SKILL.md) |

For slash commands, activate the matching bundled skill, follow its init.md and selected guideline, and resolve supporting paths relative to that skill directory.
